# TECNO HELP - Aplicación de Asistencia y Mantenimiento de Dispositivos de Oficina

## Descripción
TECNO HELP es una solución de software orientada a facilitar el soporte técnico y el seguimiento del ciclo de vida de los equipos de oficina. Permite a los usuarios reportar incidencias, solicitar mantenimientos y verificar el estado en tiempo real de sus dispositivos.

Este repositorio se utiliza como proyecto principal para la asignatura **INF-4334 - Gestión de Configuración de Software**.

## Objetivo del Proyecto
Demostrar el control de versiones y las buenas prácticas de organización de software desde su inicio, aplicando control de cambios, seguimiento de tareas mediante Issues y gestión del flujo de trabajo con GitHub Projects.

## Herramientas Utilizadas
* **Control de versiones:** Git & GitHub
* **Gestión y seguimiento:** GitHub Projects & Issues
* **Entorno de desarrollo:** Visual Studio Code
* **Tecnologías planificadas:** C# (.NET), React, SQL Server

## Organización del Trabajo
El proyecto se gestionará utilizando un tablero Kanban en GitHub Projects estructurado en las siguientes columnas:
1. **Pendiente** (Backlog / Tareas por hacer)
2. **En proceso** (Tareas en ejecución)
3. **En revisión** (Pruebas y validación)
4. **Completado** (Tareas finalizadas)
